# 瑪利歐台灣

一場從夜市出發的白天小冒險。紅帽、藍色吊帶褲的水管工穿過台北街頭、阿里山與墾丁，撞破方塊吃小籠包、彈飛 UBike，最後抵達台北 101。

**遊戲只有一個 `index.html`，上傳到 GitHub Pages 後，打開連結就能玩。** 不需要 npm、編譯或素材資料夾。

## 立即遊玩

**遊戲網址：<https://alangogoro.github.io/mariointw/>**

手機、平板、桌機瀏覽器打開即可，不需要安裝任何東西。

## 部署方式

本專案已連接到 <https://github.com/alangogoro/mariointw>，並透過 `.github/workflows/deploy-pages.yml` 自動部署到 GitHub Pages。修改 `index.html` 後推送到 `main`，Actions 會重新部署，遊戲網址不變。

```bash
git add index.html
git commit -m "update game"
git push
```

## 操作

| 操作 | 桌面 | 手機／平板 |
| --- | --- | --- |
| 左右移動 | A / D 或 ← / → | 左下方向按鈕 |
| 跳躍 | Space、W 或 ↑；按住跳得更高 | 右下「跳！」，可與方向同時按 |
| 暫停／繼續 | P、Escape 或右上暫停按鈕 | 右上暫停按鈕 |
| 重新開始 | R 或右上 ↻ | 右上 ↻ |
| 聲音 | 右上音樂、音效按鈕分別切換 | 同左 |

手機直向可以玩，橫向視野更寬。第一次按「出發」後才會播放聲音；離開分頁或視窗會自動暫停。

## 遊戲規則

- 一關、五個連續白天場景：夜市 → 台北街景 → 阿里山 → 墾丁 → 台北 101。限時 120 秒，保留約一分鐘的快速路線，也可探索高處平台。
- 全關 25 座高低平台，包含地面最多 3 層；夜市棚架、台北磚台、山林木棧道與海岸石台都有明亮頂緣。
- 10 顆金色小籠包方塊，每個場景 2 顆。從下方跳起頂破，會彈出一顆小籠包再落下；側撞或站在上面不會破。撞破本身不加分，收集小籠包才加分。
- 初始 3 顆愛心。側撞 UBike 扣一顆愛心，受傷後有 1.2 秒保護時間。
- 從上方踩倒 UBike，反彈並加 200 分。
- 收集小籠包加 300 分，獲得 **7 秒無敵**。無敵時碰到 UBike，單車旋轉飛出並加 250 分。
- 再吃一顆小籠包會將無敵倒數刷新為 7 秒，不疊加。
- 每景入口與中段設有旗幟復活點，共 10 個。落坑仍會扣血、取消無敵，回到最近通過的復活點。
- 復活保留已得分數、剩餘時間、被擊敗的敵人和道具狀態；已破方塊不會重新出現。按「重新出發」才重置整關。
- 抵達 101 入口過關；時間獎勵為剩餘秒數（向上取整）× 10。
- 最高分、BGM 及 SFX 設定儲存在目前瀏覽器。未支援儲存的環境仍可遊玩。

## 技術

HTML5 Canvas + Tailwind CSS CDN + 原生 JavaScript。畫面採程式繪製像素素材，音樂與音效由 Web Audio API 即時合成；無圖片與音訊檔案。音樂為新編 8-bit 旋律。

內含固定 60Hz 物理更新、AABB 碰撞、100ms 土狼時間、120ms 跳躍輸入緩衝、視差捲軸、DPR 高清畫布、鍵盤與多點觸控。所有遊戲程式與樣式均在 HTML 內；Tailwind CDN 和 Google Fonts 是僅有的外部載入，核心介面亦提供完整內嵌 CSS 與備用字型。

介面文字與 Canvas 招牌／浮動分數皆以螢幕實際 18 CSS px 為下限，計數器至少 24px。手機改用目前場景與下一站的精簡路線列；小螢幕選單內文可捲動，主要按鈕保持可見。

白天街景包含騎樓、紅磚立面、鐵窗、冷氣、水塔、公車站與中文店招；阿里山加入杉林、木造車站與紅色小火車，墾丁加入海岸、椰子樹、燈塔與海邊食堂。

可直接用瀏覽器開啟 `index.html`，或在本資料夾執行 `python3 -m http.server 4173 --bind 127.0.0.1`，開啟 `http://127.0.0.1:4173/` 本機預覽。本機網址只供自己的電腦使用，分享給別人請用上方 GitHub Pages 步驟。

## 驗證紀錄

已在 Chrome 驗證桌面 1440×900、手機直向 390×844 與橫向 844×390 的 HUD、控制器及選單；以瀏覽器觸控事件驗證雙指移動＋跳躍。

新版以純移動與跳躍輸入完成五景，約 67.5 秒抵達 101，保留 3 顆愛心。30 項玩法測試、77 項介面／裝置／音效測試通過；所有 25 座平台都實際落腳，10 顆方塊與 10 個復活點逐一驗證。另檢查 Canvas 招牌縮放後的字型下限，以及沒有 CDN、字型、儲存或音訊支援時仍可遊玩。

測試工具與截圖放在 `.playwright-cli/`，不需上傳；一般網址不會啟用測試用的狀態修改功能。
